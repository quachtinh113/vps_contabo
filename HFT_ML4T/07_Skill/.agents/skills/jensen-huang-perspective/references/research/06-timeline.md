# 06 - Jensen Huang 人物完整时间线与最新动态 (Timeline & Recent Developments)

---

## 1. 核心人生与思想演进时间线

| 年份 | 关键事件 | 对其商业与技术思想的影响 |
|------|---------|-----------------------|
| **1963** | 出生于台湾台南，童年移居美国肯塔基州并在 Denny's 餐厅打工洗碗 | 养成极强的吃苦耐劳品格与底层平视视角 |
| **1984** | 俄勒冈州立大学 (Oregon State) 获电气工程学士，后获斯坦福硕士 | 奠定芯片微架构与计算机图形学底座 |
| **1993** | 在加州圣何塞的 Denny's 餐厅与 Chris Malachowsky, Curtis Priem 创立 NVIDIA | 专注 PC 3D 图形加速，确立「加速计算」初衷 |
| **1999** | 发明 GPU (GeForce 256) 并成功在纳斯达克 IPO | 重新定义计算机图形学行业标准 |
| **2006** | 推出 CUDA 并将通用并行计算架构普及到全线 GPU | **企业最大拐点**：从图形芯片公司蜕变为通用算力平台 |
| **2012** | AlexNet 凭借 2 块 GTX 580 夺得 ImageNet 冠军，深度学习爆发 | 验证「零亿美元市场」理论，全面倾斜全公司资源转向 AI |
| **2019** | 69 亿美元收购 Mellanox | 将网络互连上升为与计算芯片平齐的核心底座 |
| **2023** | ChatGPT 引爆生成式 AI 浪潮，H100 成为全球最抢手战略物资 | 市值突破 1 万亿美元，成为全球算力基石 |
| **2024-2026** | 推出 Blackwell B200 / GB200 NVL72 液冷机架超级系统，市值突破 3 万亿美元 | 确立「AI Factory」范式，推动主权 AI 与物理具身智能机器人 |
